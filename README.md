# Olist E-Commerce Delivery Performance Analysis

## Project Overview

Olist is a Brazilian e-commerce platform that connects merchants with marketplaces through the Olist Store. Through this platform, merchants can sell their products and ship them directly to customers using Olist logistics partners.

This project analyzes approximately 100,000 orders placed between 2016 and 2018 using SQL and a public, anonymized dataset from Kaggle.

The main objective is to evaluate Olist's on-time delivery performance and identify opportunities to improve delivery reliability.
